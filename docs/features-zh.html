你的智能体能做什么。

你的智能体在多年的邮件中搜索，阅读附件，依据你的价目表和文档起草回复，并且只提供你日历上空闲的时间。你审阅，你批准，邮件才发出。

一封邮件，从头到尾

客户来信询价，并想约个时间见面。

从邮件到达到你的回复发出，中间发生了这些事。

  1. 01

    邮件到达

    “能把 40 件的价格发给我吗？下周能见个面吗？”

  2. 02

    智能体先做功课

    它找出与这位客户的往来邮件，阅读你的价目表，并在你的工作时间内查找日历上的空闲时段。

  3. 03

    它写好整封回复

    你的数字，你的语气，两个真实可约的时间。它请求发送，而它能做的也仅此而已。

  4. 04

    你批准，完成。

    在应用、手机或通知中批准，并用 Windows Hello 或 Touch ID 确认。邮件按你看到的原样发出。

简而言之

它可以请求发送，但不能批准。

设置21 秒

四步即可开始

连接邮箱，说明由谁回复，连接你的智能体。

脱敏15 秒

它只看到你想让它看到的。

在桌面应用中，IBAN 和电话号码会在智能体起草之前被隐藏：靠规则和校验和，不用 AI。

你的智能体能做什么

远不止一个发送按钮。

阅读、搜索、记忆和起草都无需询问你。只有会在外部留下痕迹的操作才等你决定。

什么都找得到

“我们三月发出的那份报价”只需问一句。本地归档保存每一封邮件和附件，即使服务器已经删除。

阅读附件

PDF 和办公文档对智能体来说都是文本，所以答案来自产品手册，而不是猜测。

依据你的文档起草

价目表、条款、产品资料。回复引用你的数字，文档没写的它就不说。

安排会议

只提供你工作时间内的空闲时段。日程在你批准后才创建。支持 Microsoft 365 或 Google 日历。

记住每个人

往来记录、语气和你自己的备注都保存在每位发件人旁边。给这个人起草前，它会先读这些。

自动化

“这些发件人的来信，依据这些文档生成草稿。”半自动模式每次都会问你；全自动模式只在你签署的范围内运行，带有到期时间和每日上限。

你的所有邮箱

Microsoft 365 和 IMAP：Outlook、Gmail、Aruba、Libero 以及任何服务器。多个账号在控制台中合并显示，每封回复都从正确的地址发出。

隐藏敏感信息

在桌面应用中，邮件交给智能体起草之前，脱敏器会替换税号、增值税号、IBAN 和电话号码。结果确定，不用 AI。面向 MCP 智能体的版本已在计划中。

桌面控制台还提供一个围绕智能体打造的邮件客户端：用自然语言向你的邮件提问，口述指令，查看等待你处理的请求，管理自动化，并把多个账号合并成一个列表阅读。同一个引擎，无需终端。

把收件箱交给你的智能体，最后拍板的仍是你。

免费、开源，在应用中几步即可完成设置。
