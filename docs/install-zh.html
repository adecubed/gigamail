安装

全部安装包，以及终端里的装法。

桌面应用会带你走完全部三步。这里是其余的一切：各个系统的安装包、用 pip 单独安装核心，以及手动连接邮箱和智能体的命令。

第 1 步

获取 GigaMail

一个自带 Python 的安装包：无需预装任何东西，无需管理员密码，会自动更新。

Windows 10 / 11GigaMail-Setup.exe macOS，Apple SiliconGigaMail-arm64.dmg macOS，IntelGigaMail-x64.dmg Linux，Debian / Ubuntu 测试版GigaMail-amd64.deb Linux，AppImage 测试版GigaMail-x86_64.AppImage

Windows 版已签名，macOS 版已签名并经过公证；Linux 包为测试版，未签名（Ubuntu 23.10 及更高版本请用 .deb）。SHA-256 校验值见发布页面。不需要图形界面？只装核心：

pip install "gigamail[all]"

第 2 步

连接你的邮箱

在应用中，引导流程会替你完成：Microsoft 365 在浏览器中登录，或用应用专用密码连接 IMAP。在终端中：

gigamail login                # Microsoft 365，设备代码登录
gigamail accounts add-imap    # Gmail、Aruba、Libero……
gigamail check                # 做一次搜索，生成一封等你批准的草稿

然后说明由谁回复：身份、语气，以及智能体可以引用的文件。

gigamail identity set
gigamail identity add-file ./pricelist.xlsx

凭据由你在自己的终端里输入。没有任何工具能让智能体添加账号。

第 3 步

连接你的智能体

GigaMail 自身不带 AI：智能来自你连接的智能体。应用的第三步会替你复制好准确的配置；手动配置则是下面其中一种。

这个仓库本身就是一个 Claude Code 插件：它会注册服务器，并添加一个让 Claude 了解批准关卡的技能。

claude plugin marketplace add adecubed/gigamail
claude plugin install gigamail@gigamail

把服务器加到 claude_desktop_config.json 的 mcpServers 下，然后重启 Claude Desktop。

{
  "mcpServers": {
    "gigamail": { "command": "gigamail-server" }
  }
}

作为 Codex 插件安装，带同样的技能：

codex plugin marketplace add adecubed/gigamail
codex plugin add gigamail@gigamail

或者只注册服务器，这也是 OpenAI 插件目录中的条目所要求的方式：

codex mcp add gigamail -- gigamail-server

用的是 ChatGPT 而不是终端？请看分步指南（英文）。

OpenClaw 在保存之前会先探测服务器。请把 GIGAMAIL_ROOT 指向你的 GigaMail 数据文件夹。

openclaw mcp add gigamail --command gigamail-server \
  --env "GIGAMAIL_ROOT=<你的数据文件夹>"
openclaw skills install @adecubed/gigamail   # 批准关卡技能

Hermes 只把你声明的环境变量传给 stdio 服务器，所以必须设置 GIGAMAIL_ROOT。在 ~/.hermes/config.yaml 中：

mcp_servers:
  gigamail:
    command: "gigamail-server"
    env:
      GIGAMAIL_ROOT: "<你的数据文件夹>"

用 hermes mcp test gigamail 检查。

任何能启动 stdio 服务器的 MCP 客户端都可以。命令是 gigamail-server，不占用网络端口，不需要 API 密钥。如果客户端会过滤环境变量，请声明 GIGAMAIL_ROOT。

已验证的配置、工具过滤，以及如何在手机上收到批准请求，见 INTEGRATIONS.md（英文）。
