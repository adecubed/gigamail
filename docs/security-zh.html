安全

智能体能做什么，不能做什么，以及还有哪些尚未解决。

GigaMail 让 AI 智能体访问你的邮箱。本页列出目前已有的每一项防护、我们已知的局限，以及接下来计划构建的内容。它会随每个版本更新。

批准谁来批准自动化你的数据恶意邮件桌面应用局限计划报告漏洞

智能体提议，由你决定。

智能体可以请求发送邮件，但它永远拿不到任何能用来批准自己请求的东西。

01 · 预览

智能体得到一份预览

发送、回复或删除只会返回预览和一个无效力的请求编号。智能体无法把这个编号变成实际操作。

请求 req_7f3a · 无效力
02 · 批准

你来批准，在它触及不到的地方

通过控制台、命令行、Telegram 或 Windows 通知批准，并用 Windows Hello 或 Touch ID 确认。

已暂挂 · 等待批准
03 · 执行

执行的正是你看到的内容

执行的是你审阅过的参数，绝不会被替换。每一次写入都会记入只增不改的操作日志。

已由你批准 · 已发送

有十个工具需要经过这道批准：发送和回复，移动和删除邮件，删除文件夹，创建和删除日历日程，创建 Zoom 会议，上传和删除 Drive 文件。MCP 工具图（英文）列出了全部 31 个工具及其风险等级。

与你看到的内容绑定

已批准的请求按创建时固定下来的账号、收件人、文件夹和附件执行。附件与其 SHA-256 和大小绑定：如果你批准之后磁盘上的文件被替换，发送会被拦下。

出问题时一律拒绝

如果批准记录无法读取，什么都不会执行：返回的是一个明确的拒绝，而不是一个日后可能被人屏蔽掉的错误。在无法验证真人的电脑上，批准会被拒绝，而不是退化成一个“是/否”提问。

自动化，只有你签署才生效

邮件不经点击就发出的唯一途径：你在应用中创建的规则，针对你选定的发件人和文档。半自动模式仍然每次询问；全自动模式只在你签署的范围内运行。

没有任何工具能开启规则

规则只能在应用或命令行中、经过 Windows Hello 或 Touch ID 验证后创建和恢复。没有任何 MCP 工具可以创建或修改规则，所以一封邮件无法开启自动驾驶。暂停规则不需要验证。

范围天生就窄

指定的发件人或单个文件夹，只用附加到规则上的文档，有每日上限，对同一发件人的两次回复之间有间隔，并且必须设置到期时间。绝不会是“所有邮件”。

智能体只写正文，别的不碰

收件人、主题和会话都取自收到的邮件。回复只发给触发规则的那位发件人，绝不会发给邮件或草稿里写的其他地址。

是否回复由规则决定，而不是模型

以下邮件不会自动回复：未通过发件人验证（DMARC）的邮件、自动生成的邮件、邮件列表、no-reply 发件人、垃圾邮件，以及带可执行文件或压缩包附件的邮件。新发件人的第一封邮件由你处理。短时间内匹配过多会让规则自动暂停。

每一次自动发送都会连同放行它的规则一起记入操作日志，你也会收到与批准请求相同的通知。

数据留在本地

没有 GigaMail 服务器

索引、归档、凭据、记忆和配置都在你的电脑上。GigaMail 不运行任何服务器，也不接收任何数据。智能体读取的内容由该智能体处理，适用其提供商的政策。

凭据从不经过智能体

账号由你在应用或自己的终端里添加。没有任何工具能让智能体添加账号，或读取密码、令牌或密钥。

一次只操作一个账号

每个工具都会指明它操作的账号。请求某个邮箱的智能体无法读取或写入另一个邮箱。

只限你登记过的文件

智能体只能引用你添加为知识文件的文档。不在该列表中的路径一律拒绝，链接和快捷方式也不例外。

桌面应用敏感字段已隐藏

邮件交给智能体起草之前，脱敏器会替换税号、增值税号、IBAN 和电话号码，并在草稿中把它们还原。靠规则和校验和，不用 AI。面向 MCP 智能体的同款过滤器已在计划中。

邮件是输入，不是指令

邮件内容一律视为不可信数据。藏在邮件里的指令无法添加账号、读取机密或批准发送。

智能体读到的就是你看到的

人看不到的文字（隐藏的区块、零号字体、白底白字、不可见字符）会被去掉并标记。智能体拿到的是可见文字，而不是原始 HTML。无法检查的邮件会被扣下，而不是靠猜测处理。

程序到不了智能体手里

可执行附件不会为智能体下载，会带上警告标记，在归档中则被替换为一条说明。桌面应用绝不会打开这类文件；你仍然可以自己另存。

没有链接会自动打开

智能体写出的文字在应用和 Telegram 中显示时，都不会加载图片或链接预览。携带数据的链接不经点击就无法被访问。

用恶意邮件做过测试

每次改动都会运行防注入测试；还有一套红队测试，把恶意邮件交给开启了全部工具的真实智能体，并在保护机制下只记录破坏性操作而不执行。

桌面应用把邮件当作危险地带

邮件无法运行代码

每封邮件都经过同一个过滤器，并显示在不运行任何脚本的沙箱中。链接只能作为网页或邮件地址打开。

只在本地，并由令牌保护

应用只与你电脑上它自己的后端通信，每次安装使用一个随机令牌。

已签名的发布版本

从打了标签的源代码构建。Windows 安装包和应用已签名；macOS 应用已签名并经过公证。Linux 包未签名。SHA-256 校验值见发布页面。

连接经过验证

默认检查邮件服务器的证书。使用自签名证书的服务器，只有在你通过 Windows Hello 或 Touch ID 为该账号放行后才会被接受。

它覆盖不到的地方

  • 你的智能体决定请求什么。恶意邮件仍然可能说服智能体去请求一次不明智的发送。请求会停在预览这一步：这正是设计在起作用，预览就是你该仔细看的地方。
  • 拥有终端的智能体绕开 GigaMail。如果它能以你的身份运行任意命令，就可以直接操作你的邮件程序或邮件服务商。任何邮件关卡都拦不住这一点。请保持智能体自身的命令批准功能开启。
  • 你的模型提供商。智能体读取的内容会离开 GigaMail 的边界，适用该提供商的数据政策。
  • 操作日志只增不改，但并非防篡改。任何能写入你磁盘的人都可以修改它。
  • 可见的指令。人能读到的文字仍然会到达模型。去除隐藏文字缩小了你看到的与智能体读到的之间的差距，但并没有消除它。
  • 已经被攻破的电脑或用户账号。
