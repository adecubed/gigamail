MCP map

31 tools. Each one with a risk class.

This is everything an agent can call when it connects to GigaMail over MCP, and the rule each call follows. The list is generated from the server, so it matches the version you install.

Two surfaces, one core

MCP server

For your agent. Runs over stdio: no network port to reach or protect.

Console

For you. A local HTTP API on 127.0.0.1 with a session token. Optional.

Neither has an AI of its own: the reasoning is always your agent’s.

Four risk classes

READ
18

Free

Reading, search, listings. Mail content is treated as untrusted data.

WRITE_SAFE
3

Free, logged

Small reversible changes, written to the audit log.

DANGEROUS
10

Two-phase approval

Anything that sends, deletes or invites. It waits for a person.

ADMIN
0

CLI only

Logins, credentials, accounts. Never exposed to the agent.

How two-phase approval works

  1. 1

    The agent asks

    It calls send_mail as usual. Nothing runs.

  2. 2

    GigaMail answers with a preview

    Recipients, subject, body, attachments, plus an inert request_id valid for 15 minutes.

  3. 3

    You approve, outside the agent

    From the console, the CLI, Telegram or a Windows notification, confirmed with Windows Hello or Touch ID.

  4. 4

    Then it runs

    The agent calls again with the request_id. What runs is the payload you approved, not one the agent passes back. Until then you can revoke it.

What the agent can never do

ADMIN

Sign in or out, add or remove accounts, set up CalDAV, run the indexer, configure masking, delete data. These live in the gigamail CLI only. Credentials never travel through the agent’s channel, so a prompt injection hidden in a mail cannot add an account, read a token or change the setup.

Design choices

stdio, not HTTP

There is no local port for another program to call.

account_id on every tool

No “active account” state that the agent could switch behind your back.

Append-only action log

Every WRITE_SAFE and DANGEROUS call is written with time, tool, parameters and outcome. Append-only means GigaMail never rewrites past entries; it does not make the file tamper-proof against someone with access to your disk.

Mail is data, not instructions

A DANGEROUS tool can never confirm itself: the approval comes from a person, outside the agent.
