为掌控而设计

智能体提议，由你决定。

智能体可以请求发送邮件，但它永远拿不到任何能用来批准自己请求的东西。

01 · 预览

智能体得到一份预览

发送、回复或删除只会返回预览和一个无效力的请求编号。智能体无法把这个编号变成实际操作。

02 · 批准

你来批准，在它触及不到的地方

通过控制台、命令行、Telegram 或 Windows 通知批准，并用 Windows Hello 或 Touch ID 确认。

已暂挂 · 等待批准
03 · 执行

执行的正是你看到的内容

执行的是你审阅过的参数，绝不会被替换。每一次写入都会记入只增不改的操作日志。

常见问题

智能体邮件，用大白话说。

什么是智能体邮件？

由 AI 智能体替你阅读、搜索和起草，而重要的决定仍由人来做的邮件方式。在 GigaMail 中，智能体负责准备；发送、回复和删除都等你批准。

GigaMail 支持哪些 AI 智能体？

Claude Code 和 Claude Desktop、Codex、OpenClaw、Hermes，以及任何支持 MCP 的客户端。GigaMail 自身不带 AI：智能来自你连接的智能体，它读取的内容适用该智能体的数据政策。

可以连接哪些邮箱？

通过 Microsoft Graph 连接 Microsoft 365 和 Outlook.com，以及任何 IMAP 服务器：Gmail、Aruba、Libero 等。多个账号可以并存，各自从自己的地址回复。

我的数据在哪里？

在你的电脑上。邮件索引、归档、凭据、记忆和配置都留在本地；GigaMail 不运行任何服务器，也不接收任何数据。在桌面应用中，脱敏器可以在智能体起草回复之前隐藏敏感字段。详见隐私政策（英文）。

会有邮件未经我批准就发出吗？

只有通过你在应用中创建并签署的自动化规则才会，并且受其范围、到期时间和每日上限约束。没有任何 MCP 工具可以创建或修改规则，所以智能体或邮件都无法开启规则。

GigaMail 收费吗？

不收费。桌面应用和 MCP 服务器都免费：无需账号，无需订阅，没有广告。GigaMail 以 AGPL-3.0 许可开源，发布在 GitHub 和 PyPI 上。

GigaMail 和 AgentMail 有什么不同？

AgentMail 在它自己的云端为 AI 智能体创建新邮箱，通过 API 驱动。GigaMail 把你的智能体连接到你已经在用的邮箱，运行在你的电脑上，每一次发送、回复和删除都要经过你的批准。查看逐项对比（英文）。

GigaMail 和 Composio 有什么不同？

Composio 通过它的云端为智能体提供一千多个应用的工具，登录信息由云端保管，调用也由云端发起。GigaMail 只做邮件和日历，从你的电脑运行，每一次发送、回复和删除都要经过你的批准。两者可以并用。查看对比（英文）。

GigaMail 和 Outlook 中的 Copilot 有什么不同？

Copilot 是微软内置在 Outlook 中的助手：它是 Microsoft 365 的付费附加功能（在基础许可之外，每用户每月 21 美元起），使用微软选定的模型，运行在微软的云端，只处理微软的邮箱。GigaMail 免费，运行在你的电脑上，支持 Microsoft 365 和任何 IMAP 邮箱，智能体由你选择：Claude、Codex、OpenClaw、Hermes 或任何 MCP 客户端。而且智能体无法批准自己的操作：发送和删除都等你决定，并在它触及不到的地方确认。查看对比（英文）。
