Cosa può fare il tuo agente

Molto più di un tasto Invia.

Leggere, cercare, ricordare e preparare sono liberi. Solo le azioni che lasciano una traccia fuori aspettano te.

Legge e cerca

La ricerca del provider più un indice locale: «il preventivo che abbiamo mandato a marzo» è una domanda sola. Un archivio locale conserva ogni mail e allegato, anche dopo che il server li ha tolti.

Risponde con i tuoi documenti

Allega a un account listini, condizioni e schede prodotto. La risposta cita le tue cifre e si ferma dove finiscono i tuoi documenti.

Conosce il tuo calendario

Le bozze propongono solo orari liberi, dentro il tuo orario di lavoro. Gli eventi si creano dopo la tua approvazione. Microsoft 365 o Google Calendar.

Legge gli allegati

Il testo di PDF e file Office è a disposizione dell’agente: la risposta può venire dalla brochure, non da un’ipotesi.

Ricorda le persone

Storia, tono e le tue note stanno accanto a ogni mittente. Ogni bozza per quella persona le legge prima.

Automazioni

«La posta di questi mittenti riceve una bozza da questi documenti.» In semi-auto ti chiede ogni volta; in auto lavora dentro un perimetro che hai firmato tu, con scadenza e limite giornaliero.

Tutte le tue caselle

Microsoft 365 e IMAP: Outlook, Gmail, Aruba, Libero, qualsiasi server. Più account, una sola vista nella console, e ogni risposta parte dall’indirizzo giusto.

Nasconde ciò che è sensibile

Il masker sostituisce codici fiscali, partite IVA, IBAN e numeri di telefono prima che l’agente li veda. Deterministico, senza AI.

La console desktop aggiunge un client di posta costruito attorno all’agente: fai una domanda alle tue mail in linguaggio naturale, detta un comando, vedi le richieste in attesa, gestisci le automazioni e leggi più account come un’unica lista. Lo stesso motore, senza terminale.

Il passaggio umano

L’agente propone. Decidi tu.

Un agente può chiedere di inviare un messaggio. Non riceve mai nulla con cui approvare da solo la propria richiesta.

01 · ANTEPRIMA

L’agente riceve un’anteprima

Un invio, una risposta o una cancellazione restituiscono l’anteprima e un id di richiesta inerte. L’agente può mostrarti la proposta; non può trasformare quell’id in un’azione.

richiesta req_7f3a · inerte
02 · APPROVAZIONE

Approvi tu, fuori dalla sua portata

Dalla console, dalla riga di comando, da Telegram o da una notifica di Windows. L’approvazione è confermata con Windows Hello o Touch ID: una persona davanti al computer, non un processo.

In attesa · da approvare
03 · ESECUZIONE

Parte esattamente ciò che hai visto

L’esecuzione usa gli argomenti che hai controllato, mai una sostituzione arrivata dopo. Ogni scrittura finisce in un registro delle azioni a sola aggiunta.

Approvata da te · inviata

Una mail è input, non autorità. Il contenuto dei messaggi è trattato come dato non fidato. Le credenziali non passano mai dal canale dell’agente, e nessuno strumento MCP può creare o modificare una regola di automazione: un’istruzione nascosta in una mail non può aggiungere un account, leggere un segreto o accendere l’autopilota.

Modello di sicurezza

Tre passi

Installalo con il tuo agente.

L’app desktop ti accompagna in tutti e tre. Da terminale, gli stessi passi richiedono pochi minuti.

Passo 1

Prendi GigaMail

Un installer con il suo Python: nessun prerequisito, nessuna password di amministratore, si aggiorna da solo.

Windows 10 / 11GigaMail-Setup.exe macOS, Apple SiliconGigaMail-arm64.dmg macOS, IntelGigaMail-x64.dmg

Firmati e notarizzati. Le impronte SHA-256 sono nella pagina della release. Non ti serve l’app grafica? Solo il motore:

pip install "gigamail[all]"

Passo 2

Collega la tua casella

Nell’app ci pensa la configurazione guidata: Microsoft 365 con il login nel browser, oppure IMAP con una password per le app. Da terminale:

gigamail login                # Microsoft 365, device flow
gigamail accounts add-imap    # Gmail, Aruba, Libero, ...
gigamail check                # una ricerca, una bozza in attesa di te

Poi di’ chi risponde: identità, tono e i file che l’agente può citare.

gigamail identity set
gigamail identity add-file ./listino.xlsx

Le credenziali passano da te, nella tua shell. Non esiste uno strumento con cui un agente possa aggiungere un account.

Passo 3

Collega il tuo agente

GigaMail non ha un’intelligenza propria: l’intelligenza è l’agente che colleghi. Il terzo passo dell’app copia la configurazione esatta per te; a mano è una di queste.

Il repository è un plugin di Claude Code: registra il server e aggiunge una skill che insegna a Claude il passaggio di approvazione.

claude plugin marketplace add adecubed/gigamail
claude plugin install gigamail@gigamail

Aggiungi il server a claude_desktop_config.json sotto mcpServers, poi riavvia Claude Desktop.

{
  "mcpServers": {
    "gigamail": { "command": "gigamail-server" }
  }
}

Come plugin di Codex, con la stessa skill:

codex plugin marketplace add adecubed/gigamail
codex plugin add gigamail@gigamail

Oppure registra solo il server, che è anche ciò che si aspetta la voce nella OpenAI Plugins Directory:

codex mcp add gigamail -- gigamail-server

Usi ChatGPT invece del terminale? La guida passo passo.

OpenClaw prova il server prima di salvarlo. Indica in GIGAMAIL_ROOT la cartella dati di GigaMail.

openclaw mcp add gigamail --command gigamail-server \
  --env "GIGAMAIL_ROOT=<la tua cartella dati>"
openclaw skills install @adecubed/gigamail   # la skill del passaggio di approvazione

Hermes passa ai server stdio solo l’ambiente che dichiari, quindi GIGAMAIL_ROOT è obbligatoria. In ~/.hermes/config.yaml:

mcp_servers:
  gigamail:
    command: "gigamail-server"
    env:
      GIGAMAIL_ROOT: "<la tua cartella dati>"

Verifica con hermes mcp test gigamail.

Funziona qualsiasi client MCP che sappia avviare un server stdio. Comando gigamail-server, nessuna porta di rete, nessuna chiave API. Dichiara GIGAMAIL_ROOT se il client filtra l’ambiente.

Configurazioni verificate, filtri sugli strumenti e come ricevere le approvazioni sul telefono: INTEGRATIONS.md.

Poi chiedi e basta. «Rispondi all’ultima richiesta di preventivo usando il listino.» Legge la mail, prende i numeri dal tuo file, prepara la risposta e ti chiede prima di inviare.

Domande

L’agentic email, in parole semplici.

Che cos’è l’agentic email?

Una posta in cui un agente AI legge, cerca e prepara le risposte al posto tuo, e una persona tiene le decisioni che contano. In GigaMail l’agente prepara; inviare, rispondere e cancellare aspettano la tua approvazione.

Con quali agenti AI funziona GigaMail?

Claude Code e Claude Desktop, Codex, OpenClaw, Hermes e qualsiasi client che parli MCP. GigaMail non ha un’intelligenza propria: l’intelligenza è l’agente che colleghi, e a ciò che legge si applicano le regole sui dati di quell’agente.

Quali caselle posso collegare?

Microsoft 365 e Outlook.com tramite Microsoft Graph, e qualsiasi server IMAP: Gmail, Aruba, Libero e altri. Più account affiancati, ciascuno risponde dal proprio indirizzo.

Dove stanno i miei dati?

Sul tuo computer. Indice, archivio, credenziali, memoria e configurazione restano locali; GigaMail non ha server e non riceve nulla. Il masker può nascondere i campi sensibili prima che l’agente veda un messaggio. I dettagli nella Privacy Policy.

Quanto costa GigaMail?

Niente. GigaMail è open source con licenza AGPL-3.0, su GitHub e PyPI.
