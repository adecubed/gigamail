Installazione

Tutti gli installer, e la via del terminale.

L’app desktop ti accompagna in tutti e tre i passi. Qui c’è tutto il resto: l’installer per ogni sistema, solo il motore con pip, e i comandi per collegare a mano casella e agente.

Passo 1

Prendi GigaMail

Un installer con il suo Python: nessun prerequisito, nessuna password di amministratore, si aggiorna da solo.

Windows 10 / 11GigaMail-Setup.exe macOS, Apple SiliconGigaMail-arm64.dmg macOS, IntelGigaMail-x64.dmg Linux, Debian / Ubuntu betaGigaMail-amd64.deb Linux, AppImage betaGigaMail-x86_64.AppImage

Windows firmato, macOS firmato e notarizzato; i pacchetti Linux sono in beta e non firmati (da Ubuntu 23.10 in poi usa il .deb). Le impronte SHA-256 sono nella pagina della release. Non ti serve l’app grafica? Solo il motore:

pip install "gigamail[all]"

Passo 2

Collega la tua casella

Nell’app ci pensa la configurazione guidata: Microsoft 365 con il login nel browser, oppure IMAP con una password per le app. Da terminale:

gigamail login                # Microsoft 365, device flow
gigamail accounts add-imap    # Gmail, Aruba, Libero, ...
gigamail check                # una ricerca, una bozza in attesa di te

Poi di’ chi risponde: identità, tono e i file che l’agente può citare.

gigamail identity set
gigamail identity add-file ./listino.xlsx

Le credenziali passano da te, nella tua shell. Non esiste uno strumento con cui un agente possa aggiungere un account.

Passo 3

Collega il tuo agente

GigaMail non ha un’intelligenza propria: l’intelligenza è l’agente che colleghi. Il terzo passo dell’app copia la configurazione esatta per te; a mano è una di queste.

Il repository è un plugin di Claude Code: registra il server e aggiunge una skill che insegna a Claude il passaggio di approvazione.

claude plugin marketplace add adecubed/gigamail
claude plugin install gigamail@gigamail

Aggiungi il server a claude_desktop_config.json sotto mcpServers, poi riavvia Claude Desktop.

{
  "mcpServers": {
    "gigamail": { "command": "gigamail-server" }
  }
}

Come plugin di Codex, con la stessa skill:

codex plugin marketplace add adecubed/gigamail
codex plugin add gigamail@gigamail

Oppure registra solo il server, che è anche ciò che si aspetta la voce nella OpenAI Plugins Directory:

codex mcp add gigamail -- gigamail-server

Usi ChatGPT invece del terminale? La guida passo passo.

OpenClaw prova il server prima di salvarlo. Indica in GIGAMAIL_ROOT la cartella dati di GigaMail.

openclaw mcp add gigamail --command gigamail-server \
  --env "GIGAMAIL_ROOT=<la tua cartella dati>"
openclaw skills install @adecubed/gigamail   # la skill del passaggio di approvazione

Hermes passa ai server stdio solo l’ambiente che dichiari, quindi GIGAMAIL_ROOT è obbligatoria. In ~/.hermes/config.yaml:

mcp_servers:
  gigamail:
    command: "gigamail-server"
    env:
      GIGAMAIL_ROOT: "<la tua cartella dati>"

Verifica con hermes mcp test gigamail.

Funziona qualsiasi client MCP che sappia avviare un server stdio. Comando gigamail-server, nessuna porta di rete, nessuna chiave API. Dichiara GIGAMAIL_ROOT se il client filtra l’ambiente.
